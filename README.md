# D_A_Enfermedades_Cardiovasculares
Una Startup enfocada en Health-Tech Quieren integrar en su software de historia clínica electrónica una herramienta  que alerte a los médicos si un paciente tiene indicios de presencia de enfermedad cardíaca, basándose en sus resultados de laboratorio y signos vitales. Dataset: https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset
